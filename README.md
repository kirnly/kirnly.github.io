## Overview

Kirnly is a calm, focused editor for writing Kirn. It brings project navigation, readable diagnostics, and a tight write-check-run workflow closer to the language.

## Local development

This is a static GitHub Pages website. No build step is required. Serve the repository locally with:

```bash
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.
